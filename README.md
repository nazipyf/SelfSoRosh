# Self Telegram — Test Project

Android project starter for the two-screen Self Telegram app.

## Included now
- Dark black/purple two-screen UI
- Message text, destination link and interval fields
- Start/stop state and status
- Saved message templates (local)
- Destination list (local)
- Activity log and message counter placeholder
- Settings and creator link
- Local persistence for basic fields

## Important limitation
This is a UI/test build, not yet connected to Telegram's personal-account MTProto API. The Start button currently starts a local demo timer/status only; it does NOT send Telegram messages. Do not treat this as a working sender until the Telegram login/API integration has been implemented and tested.

## Build
Open in Android Studio and build an APK, or use the included GitHub Actions workflow by uploading this project to a GitHub repository.
